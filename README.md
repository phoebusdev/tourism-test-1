# Voskopojë Tourism Website

A professional, visually stunning tourism website for Voskopojë (Moscopole), the historic "Paris of the Balkans" in Albania.

## 🌟 Overview

This website showcases the rich history, cultural heritage, and natural beauty of Voskopojë, a historic mountain village in southeastern Albania. The site is built to the highest industry standards with a focus on performance, SEO, accessibility, and user experience.

## ✨ Features

### Content
- **Comprehensive Information**: Accurate, factual content sourced from credible educational resources
- **Rich History**: Timeline of Voskopojë from the 14th century to present
- **Cultural Heritage**: Detailed information about Byzantine churches and frescoes
- **Nature & Activities**: Hiking trails, natural attractions, and outdoor activities
- **Practical Information**: Travel guides, best times to visit, and accommodation details

## 🚀 Getting Started

### Local Development

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd tourism-test-1
   ```

2. **Open in browser**
   - Simply open `index.html` in your web browser
   - Or use a local server:
     ```bash
     # Python 3
     python -m http.server 8000

     # Python 2
     python -m SimpleHTTPServer 8000

     # Node.js (with npx)
     npx http-server
     ```

3. **View the site**
   - Open `http://localhost:8000` in your browser

### Deployment

This is a static website and can be deployed to:
- **GitHub Pages**: Enable in repository settings
- **Netlify**: Drag and drop the folder
- **Vercel**: Connect to Git repository
- **AWS S3**: Upload files to S3 bucket with static hosting
- **Any web server**: Upload files via FTP/SFTP
